Overview
Split Terminal is a puzzle game designed in the form of levels made with just plain HTML, CSS and JavaScript. It involves an asymmetrical two-layer system, where the player has to move through and coordinate movements in the two parallel sectors named Sector Alpha (Physical Layer) and Sector Beta (Anomaly Layer) to escape the containment area.

Core Mechanics

Dual Layer Coordination: Coordinate control of positions in two separate grids, either independently or together.

Asymmetrical Components: The components such as movable data blocks, anomaly areas and barriers have different properties in each layer.

Laser Walls: High Energy walls which impose desynchronization penalties if crossed when active. They can be turned on or off using switch tiles.

Control Mode Change: Stepping on swap tiles allows changing control to both, Alpha or Beta.

Controls

Navigate Grid: W A S D or Arrow Keys

Undo Last Move: Z

Restart Sector: R

Toggle CRT Overlay: Click CRT toggle in header

Select Sector: Click sectors directory menu

Structure of the Project

index.html: The main game display window

style.css: Styling for the terminal

app.js: The main game engine

To run it:

Download this repo and open index.html in your desired browser.
